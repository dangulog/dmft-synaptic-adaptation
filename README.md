# Dynamic Mean-Field Theory with Synaptic Adaptation

This repository contains the code used to simulate and analyze a dynamic mean-field theory (DMFT) model with synaptic adaptation.

The main objective is to provide the numerical methods, analyses, and scripts required to reproduce the results and figures associated with this research project.

## Project status

This repository is currently under development. The code, software dependencies, and detailed reproduction instructions will be added progressively.

## Repository contents

The repository will include:

* implementations of the mathematical model;
* numerical simulation and analysis scripts;
* notebooks used to explore the results;
* scripts for reproducing the figures;
* documentation of the required software environment.

## Reproducibility

Detailed instructions for installing the dependencies and reproducing the numerical results will be provided as the repository is organized.
